# 🎄🎱 Loto de Noël 2026 – APEL Notre Dame

Le flyer du Loto de Noël de l'APEL du collège Notre-Dame et de l'école Saint-Joseph de Broons.

**Samedi 5 décembre 2026 à 20h00**, salle des fêtes de Broons (ouverture 18h30). Animé par JCO Animation.

## Le flyer

[📄 Ouvrir le flyer](https://apelnotredamebroons.github.io/loto-2026/flyer.html) : 2 flyers par A4 paysage (à découper), ou 1 flyer en A5.

## Imprimer

1. Ouvrir le flyer avec **Chrome** ou **Edge**.
2. Cliquer sur le bouton 🖨️ de la ligne « 2 par page A4 » (celui de la ligne « A5 » imprime un seul flyer sur une feuille A5).
3. Dans la fenêtre d'impression, ouvrir « Plus de paramètres », puis :
   - Marges : **Aucune** ;
   - cocher **Graphiques d'arrière-plan**.

## Mettre le site en ligne (GitHub Pages)

À faire une seule fois :

1. Créer un dépôt **public** nommé `loto-2026`.
2. Cliquer sur **Add file › Upload files**, puis glisser tous les fichiers de ce dossier, **y compris le dossier `fonts`** (les polices du flyer).
3. Ouvrir **Settings › Pages**. Dans « Source », choisir **Deploy from a branch**, puis la branche `main` et le dossier `/ (root)`. Cliquer sur **Save**.
4. Au bout d'une à deux minutes, le site est en ligne à l'adresse <https://apelnotredamebroons.github.io/loto-2026/>.

La page d'accueil du site est ce README.

Pour modifier le flyer, il suffit de déposer à nouveau le fichier modifié (**Add file › Upload files**) : le site se met à jour tout seul.
